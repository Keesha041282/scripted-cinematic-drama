# Scripted Cinematic Drama

A VideoExpress workflow for turning your full episode script into a cinematic photorealistic drama.

1. Open a chat that can use VideoExpress through an available browser tool.
2. Paste the [launch prompt](SYSTEM_PROMPT.md).
3. Provide your episode topic, full script, and labeled character reference images.

The default finished runtime is **9–10 minutes**, with **vertical 9:16** framing and **American English accents**. The workflow follows the script’s story days, keeps character identities consistent, and updates wardrobe when the story calls for it. Cast size, script length, and line length are uncapped by the workflow.

See the [production playbook](PLAYBOOK.md) for the full instructions. This public fork credits [ai-playbooks/realistic-mini-dramas](https://github.com/ai-playbooks/realistic-mini-dramas).
